Contact

Something needs a closer look?

Send guide corrections, accessibility feedback, and website problem reports to mooyuking@gmail.com. This is an email contact, not an instant support service.

For a guide correction

Include the page, the statement you are questioning, the game version if known, and a public reference or a concise description of what happened. Please distinguish a repeatable result from a theory about the story.

For a website problem

Tell us your browser and device, the action you attempted, and the visible result. Avoid sending passwords, account tokens, or private files. If the player stays blank, include the loading message and whether reloading helped.

Rights and attribution

For concerns about a screenshot, illustration, or reference, identify the material and the rights involved so the issue can be reviewed. We cannot make changes to external video channels or the game developer's services.
